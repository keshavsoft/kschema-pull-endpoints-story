Toolchain Requirements

Development Dependencies

The developer toolchain required to run checks, run local testing suites, and manage package publication pipelines.

Required Environment Components

The project runs zero external package development dependencies (to ensure a light and secure tree), relying instead on native runtime utilities.

🟢

Node.js Runtime

Uses Node.js (version 20+ or 22+) built-in capabilities to run recursive filesystem operations and ES modules statically.

📦

NPM Package Manager

Manages project workspaces, test runner triggers, and handles publishing packaging targets directly to registries.

🌿

Git Version Control

Triggers conditional workflow tasks on push actions and stages documentation builds automatically.
