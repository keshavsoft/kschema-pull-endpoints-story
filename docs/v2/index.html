Features Built for Story Analysis

Designed around efficiency, version isolation, code story parsing, and programmatic integration.

🔍

Automated Scouting

Scans the filesystem recursively to find all end-points.js files using the kschema-pull-endpoints engine.

📦

Dynamic Versioning

Under the hood, scans the executable registry to run the latest runtime runner (currently v3) seamlessly.

📖

Story Extraction

Parses the content of each file to extract detailed route definitions, imports, and variables connection patterns.

⚡

Clean Programmatic API

Returns a flat array of absolute paths, relative paths, and parsed stories for seamless route compilation.
